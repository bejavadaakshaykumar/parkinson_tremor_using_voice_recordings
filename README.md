# Parkinson's Voice Analytics

An advanced Streamlit dashboard for biomedical voice signal analysis, designed to detect Parkinson's disease using state-of-the-art machine learning techniques.

## Features

- **Subject-Wise Cross-Validation:** Zero data leakage by grouping CV folds strictly by patient ID (`GroupKFold`).
- **Robust Imbalanced Data Handling:** Applies SMOTE strictly inside training folds using `imblearn` pipelines.
- **Hybrid Feature Selection:** Utilizes L1-regularized `LinearSVC` to strip noisy acoustic features.
- **Heavy-Duty Stacking Ensemble:** Combines `HistGradientBoostingClassifier`, `RandomForestClassifier`, and `SVC`, with a `LogisticRegression` meta-classifier.
- **SHAP Explainability:** Transparent predictions with visual feature contributions for the dominant base model.
- **Interactive UI:** Feature deep dives, real-time prediction sliders, and live voice recording integration (`audio_recorder_streamlit`).
- **Clinical Reports:** Generates automated, downloadable `.docx` medical reports summarizing the AI screening.

## Installation

1. **Clone the repository:**
   (Or extract the contents of the folder)

2. **Install the dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Dataset:**
   Download the UCI Parkinson's Dataset (`parkinsons.data` or `parkinsons_dataset.csv`) and place it in the same directory as `app.py`. Ensure the filename matches `parkinsons_dataset.csv` or adjust the `load_data()` function in `app.py` accordingly.

## Usage

Run the Streamlit application:

```bash
streamlit run app.py
```

## Dashboard Tabs

1. **Overview:** High-level metrics, class distribution, recordings per patient, and feature radar/correlation charts.
2. **Feature Deep Dive:** Granular analysis of acoustic feature groups (Jitter, Shimmer, Frequency, etc.) using violin and box plots.
3. **ML Model:** Detailed performance metrics (Accuracy, F1, Sensitivity, Specificity), per-fold CV scores, confusion matrix, ROC curve, and global SHAP feature importance.
4. **Predict:** Interactive sliders to adjust voice features and see real-time prediction confidence with SHAP waterfall plots.
5. **Data Explorer:** Filter and browse the raw dataset, view summary statistics, and download filtered CSVs.
6. **Voice Predict:** Upload a `.wav` file or record live audio to extract acoustic features, get a prediction, and download a clinical `.docx` report.
